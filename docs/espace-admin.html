Espace cadre

Comptes des cadres

Créer un compte, le rattacher à ses services, réinitialiser un code PIN oublié, débloquer un compte après plusieurs essais manqués, ou régénérer un code d'accès. Ces actions se faisaient jusqu'ici directement dans le document Grist.

Nouveau cadre

L'adresse e-mail est calculée automatiquement par le document Grist à partir du nom et du prénom : elle ne se saisit pas ici.

C'est votre propre compte : vous ne pouvez ni le désactiver, ni vous retirer vos droits d'administration. Un autre administrateur le peut.

Un cadre doit être rattaché à au moins un service ouvert aux étudiants pour ouvrir l'espace cadre. Les services dont il est le référent (ou dont il est CSS de pôle) sont affichés mais se modifient dans Grist.
