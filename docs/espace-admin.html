Espace cadre

Comptes des cadres

Créer un compte, le rattacher à ses services, réinitialiser un code PIN oublié, débloquer un compte après plusieurs essais manqués, ou régénérer un code d'accès. Ces actions se faisaient jusqu'ici directement dans le document Grist.

Services et sites

Les services que voient les étudiants et les cadres. Un service n'accueille des étudiants que si sa case est cochée : c'est ce qui le fait apparaître dans la page d'inscription. Un service ne se supprime pas — il se ferme, pour ne pas perdre les stages qui s'y rattachent.

Pôles et cadres supérieurs

Le cadre supérieur de santé d'un pôle accède à tous les services de son pôle, sans avoir à être rattaché service par service. Le rattachement d'un service à son pôle se règle dans l'onglet Services.

Organigramme

Qui fait quoi, et où. Récapitulatif construit à partir des sites, des pôles, des services et des rattachements de chaque cadre.

    Code d'accès

    Transmettez-le au cadre par un canal sûr (en main propre, ou un message distinct du lien de connexion). Le code PIN, lui, n'est pas transmis : le cadre le choisit à sa première connexion.

    Nouveau service

    Décochée, cette case retire le service de la page d'inscription et ferme l'espace cadre pour ceux qui n'ont que celui-ci. Les stages déjà enregistrés restent intacts.

    Nouveau pôle

    Le cadre supérieur accède à tous les services rattachés à ce pôle, avec les mêmes droits qu'un cadre de service.

    Nouveau site

    Le site regroupe des services : un hôpital, un EHPAD, une résidence.
